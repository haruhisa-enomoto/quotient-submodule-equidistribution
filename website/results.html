Common setup

For the paper-facing main theorem, $K$ is an algebraically closed field, $A$ is a finite-dimensional $K$-algebra, and the canonical isomorphism classes of indecomposable right $A$-modules are finite. A right module is encoded as a module over $A^{\mathrm{op}}$.

For each $i$, let $q_i$ count quotient-closed supports of cardinality $i$ and $s_i$ count submodule-closed supports of cardinality $i$. The conclusion is the polynomial, or equivalently levelwise, equality

$$\forall i,\ q_i=s_i \qquad\Longleftrightarrow\qquad \sum_i q_i t^i=\sum_i s_i t^i.$$

The universal proposition is OpConjecture.RightQuotientSubmoduleEquidistribution. It is defined and related to level counts, but not proved for every representation-finite algebra.

Main four-case theorem

If the representation-finite algebra $A$ has at most nine indecomposable right modules, is Nakayama, has $\operatorname{rad}(A)^2=0$, or is representation-directed, then the quotient and submodule level polynomials agree.

First and last four coefficients

For every finite-dimensional algebra node $B$, Lean proves

$$q_i(B)=s_i(B)\quad(0\le i\le4),\qquad q_{n-i}(B)=s_{n-i}(B)\quad(0\le i\le4),$$

where $n$ is the number of indecomposable labels. If $n\le9$, those two ranges cover all degrees and give full equidistribution.

What the status means

All production declarations compile with the pinned toolchain and Mathlib revision, without source-level project axioms, sorry, or admit. Kernel-visible axiom output is generated from Audit.lean. The first/last-four classifier uses native bv_decide LRAT-certificate checks, so Lean reports generated native axioms and the compiler/interpreter are trusted for that branch. The three standalone structural-class endpoints report only propext, Classical.choice, and Quot.sound.

This establishes compiler checking and exact theorem-interface coverage. It does not by itself constitute an independent line-by-line mathematical audit of every proof body.
