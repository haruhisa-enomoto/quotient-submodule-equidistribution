Common setup

Let $K$ be an algebraically closed field and let $A$ be a representation-finite finite-dimensional $K$-algebra. Write $\mathcal L_Q^i(A)$ and $\mathcal L_S^i(A)$ for the quotient-closed and submodule-closed additive subcategories containing $i$ indecomposable isomorphism classes, respectively. Right $A$-modules are encoded as modules over $A^{\mathrm{op}}$.

Put $q_i(A)=|\mathcal L_Q^i(A)|$ and $s_i(A)=|\mathcal L_S^i(A)|$. Quotient-submodule equidistribution is the equality

$$q_i(A)=s_i(A)\ \text{for every }i, \qquad\text{equivalently}\qquad \sum_i q_i(A)t^i=\sum_i s_i(A)t^i.$$

The declaration QuotientSubmoduleEquidistribution.RightQuotientSubmoduleEquidistribution expresses this proposition. The proposition remains open for a general representation-finite algebra.

Main four-case theorem

If the representation-finite algebra $A$ has at most nine indecomposable right modules, is Nakayama, has $\operatorname{rad}(A)^2=0$, or is representation-directed, then the quotient and submodule level polynomials agree.

First and last four coefficients

Put $N=|\operatorname{ind} A|$. Lean proves

$$q_i(A)=s_i(A)\quad(0\le i\le4),\qquad q_{N-i}(A)=s_{N-i}(A)\quad(0\le i\le4).$$

If $N\le9$, the two ranges contain every degree, so all coefficients agree.

Four-vertex translation-quiver verification

The finite calculation used by the paper's four-vertex pattern classification is published as a standalone Python program. It exhausts loop-free arrow relations, projective subsets, and partial translations on four labeled vertices, evaluates the factor-ladder recurrence, and checks the classification while reproducing 6,933 labeled admissible patterns in 329 isomorphism classes.

Mixed coordinates as ideal-quotient Hom dimensions

Order the indecomposable modules as $X_1,\ldots,X_N$. For a set $D$ of omitted positions, put $\mathcal C_D=\operatorname{add}\{X_i\mid i\notin D\}$. If the subword on the positions in $D$ is reduced, then for $a,x\in D$ the formalization proves

$$\mu_D(a,x)=\dim_K\bigl((\operatorname{mod}A)/[\mathcal C_D]\bigr)(X_a,X_x)\ge 0.$$

The corresponding constructions for $A$ and $A^{\mathrm{op}}$ enter the quotient and submodule parametrizations.

Checked source and axioms

All production declarations compile with the pinned toolchain and Mathlib revision, without source-level project axioms, sorry, or admit. Kernel-visible axiom output is generated from Audit.lean. The first/last-four classifier uses native bv_decide LRAT-certificate checks, so Lean reports generated native axioms and the compiler/interpreter are trusted for that branch.
