Supporting constructions

Hom spaces in an ideal quotient

Order the indecomposables as $X_1,\ldots,X_N$. For an omitted-position set $D$, put $\mathcal C_D=\operatorname{add}\{X_i\mid i\notin D\}$. If the subword on $D$ is reduced, IyamaFactorCategoryARWord.lean constructs the induced Auslander–Reiten translation and middle terms in $(\operatorname{mod}A)/[\mathcal C_D]$. Exact right $\tau$-sequences for representable functors identify the mixed coordinates with Hom-space dimensions.

Deletion chains in finite closed intervals

FiniteInterval.lean and ConvexStructure.lean identify finite independent sets with compact closed sets and construct successive extreme-point deletions whenever the difference of two closed sets is finite. The ground set may be infinite.

Dependencies

Theorem library

The root Lake project directly requires Mathlib commit 28313485…8fe. Eleven foundational modules adapted from TauCeti are maintained as attributed local source.

Verification and documentation

Comparator and doc-gen4 are configured in the nested verification/ and docbuild/ Lake projects, each with its own manifest.

result declaration

Verification layers

  1. Kernel compilation: lake build MainResults checks the proof terms required by the declarations in the theorem index.
  2. Finite translation-quiver verification: python3 verification/four_vertex_patterns.py exhausts the four-vertex census and checks the paper's hook and hookless-pattern classification.
  3. Repository checks: tools/check_release.py checks the direct dependency, verifies that production source contains no sorry, admit, or project-local axiom, and validates theorem metadata, challenge configurations, and static links.
  4. Axiom report: lake env lean Audit.lean records each target's kernel-visible axiom set.
  5. Statement comparison: the nested challenges state the result types in environments formed from their common dependencies; Comparator configurations cover the three theorems with the standard axiom set.
  6. Navigation: doc-gen4 renders the declaration API, and the graph generator derives interactive import graphs from the local Lean import lines.
