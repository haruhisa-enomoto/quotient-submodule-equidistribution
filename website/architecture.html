Dependency boundary

Production

The root Lake project pins one direct dependency: Mathlib commit 28313485…8fe. Adapted foundational code is vendored as attributed local source, so there is no TauCeti package or import.

Verification layers

  1. Kernel compilation: lake build MainResults checks all transitive proof terms required by the advertised results and the synchronized paper-facing support declarations.
  2. Finite translation-quiver verification: python3 verification/four_vertex_patterns.py exhausts the four-vertex census and checks the paper's hook and hookless-pattern classification.
  3. Source release checks: tools/check_release.py checks the direct dependency, forbidden production holes and axioms, target metadata, challenge configs, and static links.
  4. Axiom report: lake env lean Audit.lean records each target's kernel-visible axiom set.
  5. Independent target statements: the nested challenges restate result types without importing solution modules; strict Comparator configs cover the three standard-axiom class endpoints.
  6. Navigation artifacts: doc-gen4 renders the declaration API and the release script derives interactive project-only graphs from local Lean import lines.
