# Quotient-submodule equidistribution in Lean

**Website:** [Mathematical overview, theorem map, and Lean API documentation](https://haruhisa-enomoto.github.io/quotient-submodule-equidistribution/)

**Essay:** [I Quit Math, Then Wrote a Paper with AI](https://haruhisa-enomoto.github.io/quotient-submodule-equidistribution-essay/)

This repository contains a Lean 4 formalization accompanying Haruhisa
Enomoto's manuscript *An equidistribution conjecture for quotient-closed and
submodule-closed subcategories*
([arXiv:2608.18024](https://arxiv.org/abs/2608.18024)).  The root
Lake project has one direct dependency, a fixed Mathlib revision.

Let `q_i(A)` and `s_i(A)` be the numbers of quotient-closed and
submodule-closed additive subcategories containing exactly `i`
indecomposable isomorphism classes.  The universal conjecture asserts
`q_i(A) = s_i(A)` for every `i`; it is stated in Lean but remains open in
general.

The main theorem assumes that `K` is algebraically closed and that `A` is a
representation-finite finite-dimensional `K`-algebra.  Lean proves the
conjecture under each of the following additional hypotheses:

1. `A` has at most nine indecomposable right modules up to isomorphism;
2. `A` is a Nakayama algebra;
3. the Jacobson radical of `A` has square zero;
4. `A` is representation-directed.

Right `A`-modules are represented as finitely generated modules over `Aᵐᵒᵖ`.
The standalone Nakayama theorem is formalized over an arbitrary field; the
four-case theorem uses the algebraic-closedness hypothesis of the manuscript.

## The representation-directed case

For a representation-directed algebra, the formalization constructs the
ordered Auslander--Reiten word, proves that it is reduced, and parametrizes
the quotient-closed and submodule-closed supports by the same principal
Bruhat interval.  Both level polynomials equal the reverse Coxeter-length
polynomial of this interval.

Let `D` be a set of omitted positions, and let `C_D` be the additive
subcategory generated by the indecomposables in the complementary positions.
If the `D`-subword is reduced, the declaration

```text
QuotientSubmoduleEquidistribution.RepresentationDirected.FactorARWord.
  selectedWordMixedMultiplicityFor_eq_factorHomDimension_of_reduced
```

identifies each mixed coordinate `mu_D(a,x)` with the dimension of the Hom
space from `X_a` to `X_x` in the ideal quotient `(mod A)/[C_D]`.  Its
nonnegativity follows from this equality.  The algebra-level declarations
apply this ideal-quotient Hom formula to the ordered Auslander--Reiten words
of `A` and `Aᵐᵒᵖ`.

## Convex-geometric statements

The declarations
`SetClosure.finiteIndependentEquivCompactClosedSet`,
`SetClosure.finiteIntervalDeletionChain`, and
`IndecomposableSkeleton.qClosed_finiteIntervalDeletionChain_of_finiteDimensional`
identify finite independent sets with compact closed sets and construct
successive extreme-point deletions across a finite interval of closed sets.
The quotient-closed specialization records a relative splitting projective at
each deletion.

## Four-vertex translation-quiver verification

[`verification/four_vertex_patterns.py`](verification/four_vertex_patterns.py)
exhaustively enumerates the data in the manuscript's definition of an
admissible four-vertex pattern: a loop-free arrow relation, a nonempty set of
projective vertices, a partial translation, and the associated factor-ladder
recurrences.  Assertions in the program check the hook and hookless
classification.  The enumeration gives 6,933 labeled admissible patterns in
329 isomorphism classes.  [`verification/README.md`](verification/README.md)
records the precise input, command, assertions, and expected output.

## Build and verify

The pinned toolchain is Lean 4.32.0.  From the repository root:

```text
lake update
lake exe cache get
lake build MainResults
lake env lean Audit.lean
python3 verification/four_vertex_patterns.py
python3 tools/check_release.py
```

`lake build QuotientSubmoduleEquidistribution` checks the complete library.
The final command checks the pinned direct dependency, production source,
target metadata, verifier checksum, and static-site links.

## Local website preview

The local preview combines the hand-written pages with the generated doc-gen4
API.  Build the API documentation once from the repository root:

```text
cd docbuild
MATHLIB_NO_CACHE_ON_UPDATE=1 lake update doc-gen4
lake build QuotientSubmoduleEquidistribution:docs
cd ..
```

Then run:

```text
python3 tools/serve_site.py
```

Open `http://localhost:8000/`.  The preview is assembled in a temporary
directory, so stopping the server with `Ctrl+C` leaves the repository
unchanged.

## Checked source and axioms

The production source contains no `sorry`, `admit`, or project-local `axiom`.
[`Audit.lean`](Audit.lean) reports the compiler-visible axioms of the public
theorems.  The first/last-four classifiers use Lean 4.32's `bv_decide`; its
native LRAT-certificate checks add the Lean compiler and interpreter to the
trusted base for that branch.  [`TRUST.md`](TRUST.md) gives the result-by-result
axiom boundary.

[`formalization.yaml`](formalization.yaml) records the theorem declarations
and source files in a machine-readable form.  The nested
[`verification`](verification/) project contains separate statement modules
and Comparator configurations.
